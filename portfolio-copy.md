# Portfolio copy — two project intros

## 1. GetUp + Risk Monitor

GetUp is a live web experience paired with a working Risk Monitor that makes the consequences of an agent action legible before consent. The case study links the GetUp page, the Risk Monitor interface, and the corresponding source code.

## 2. Agent risk classifier + OpenCode

The agent risk-delete classifier is trained to recognize destructive file-deletion requests and is integrated into OpenCode as an in-product safety layer. The case study links both the classifier training repository and its integration inside the OpenCode system.
